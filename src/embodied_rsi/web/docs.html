01项目背景

Embodied Lab 是一个机械臂决策与学习实验台。 模型根据环境选择动作，MuJoCo 验证物理结果，成功经验用于训练下一版模型。主任务是用 Franka Panda 抓取方块并放入目标盘。

选择动作、执行动作、完成任务是三件事。 闭爪可能空抓，搬运可能失抓，到达目标也可能尚未稳定。系统分别记录模型选择、实际执行和最终结果，让成败可追溯。

代码来源： embodied_jev 负责模型接口、感知与物理实验； embodied_rsi 负责采集、训练、评测与部署。embodied_lab 统一启动，一个 8092 服务提供完整工作台。

  1. 决策能力如何测量？

    固定场景、动作与观测，检查模型是否依据真实反馈行动；同时记录程序提供的技能与几何辅助。

  2. 成功经验如何进入学习？

    把完整成功局中的真实决策转成训练样本。探索改变采样，训练更新权重。

  3. 怎样证明新版本更好？

    在相同新场景上比较父模型与候选，检查提升、置信区间与风险；训练 loss 不能单独决定发布。

研究范围：受约束的桌面仿真。 任务、候选动作与部分几何知识由程序定义；当前不控制真实机器人，仿真成绩也不能直接外推到真实硬件或开放任务。

02项目概览

两个闭环，共用一条证据链。 局内循环负责观察、决策与执行；跨局循环负责筛选、训练、评测与发布。浏览器展示过程，后端执行并保存记录。

任务、输入与输出

实验条件 = 模型 + 任务 + 场景 + 执行配置。 配置包括种子、动作、观测、相机与预算。输出包括物理结果、回放、请求记录和指标；进入训练闭环才会生成新权重。

任务目标与差异当前用途
搬运入盘 · transfer抓取、夹持搬运、释放并撤离；严格协议还检查抬升、掉落和稳定放置。自主训练的主任务，也可用于模型测试与对比。
方块堆叠 · stack放到另一方块上；目标高度与支撑面不同。模型测试与对比；是否进入某次评测以运行配置为准。
越障搬运 · barrier避开障碍物，同时保持夹持；终点相似，路径要求可能不同。用于观察路径选择、碰撞和失败恢复。

任务 ID 决定成功条件。 新的文字指令不会自动改写场景或评分规则；新增任务需同步实现环境、动作协议和评价。

先分清这些实验单位

概念在本项目中的含义
策略 / 模型根据观测从候选中选择。规则、本地或远端模型均可决策；当前权重更新仅适配本地 RSI。
候选 / 决策候选是程序定义的选项，决策是模型的回答；顺序、说明与状态共同组成输入。
动作步 / 整局动作步是一次可能执行或被拒绝的尝试。整局从初始化到终止，包含多步；一步也可能有多次决策。
运行 / 训练轮次运行 ID 关联配置、事件与产物。一轮训练包括取数、拟合、开发选点和独立评测。
检查点 / 发布版本检查点保存权重和元数据；发布版本是通过验收、供后续推理使用的检查点。

从配置到实验，再到自进化

入口适合做什么
模型配置保存连接与预设，用决策探针检查接口。保存不调用模型，也不训练。
模型测试运行一个模型或基线，查看真实输入、选择、执行和失败原因。
模型对比固定场景、动作、观测与预算，顺序比较模型的整局结果、调用数和耗时。
自主训练本地 RSI 连续采集，达标后过滤、拟合、评测与发布。右侧看过程，下方看完整报告。

共享代码，不共享同一局实验。 测试、对比与训练各自管理会话；切换页面后需确认当前模型和参数。远端推理连接不会自动成为可训练模型。

实时控制闭环与模型更新闭环

一局之内：观察 → 选择 → 执行 → 再观察

依据物体、夹爪与接触反馈选择下一步；失败结果进入后续观测。每局固定模型版本，探索只调整采样。

跨越多局：筛选 → 拟合 → 评测 → 发布

成功整局形成回放样本，训练器更新决策头。开发集选出候选，独立场景决定是否发布；新版本从下一局生效。

默认方法：按物理结果筛选的自模仿学习。 成功轨迹提供动作标签，失败轨迹支持诊断与探索；失败本身不直接触发梯度更新。独立策略梯度实验使用另一套目标。

沿着一次搬运理解数据流

示例，不是新测得的成绩。 固定种子、技能模式与仿真真值后，一局通常经历接近、抓取、抬升、搬运、释放和撤离；实际顺序取决于协议与反馈。

  1. 看输入

    核对物体、TCP、夹爪、接触和候选。中央视图不等于模型输入。

  2. 看结果

    闭爪不等于抓住。 检查双指接触与夹持状态，再决定下一步。

  3. 看整局

    按当前协议判定整局成功；局部动作正确，不会让失败整局成为成功训练数据。

  4. 看版本

    轨迹通过过滤才进入训练；候选通过评测才发布。对照下一局的 checkpoint 哈希确认切换。

完成率、loss 和延迟分别说明什么

指标如何解释
采集成功率当前场景、预算与探索策略下的成功比例，不等同于独立评测成绩。
回放 loss对成功动作标签的拟合误差；下降不保证多步任务完成率提升。
配对完成率提升同一批独立场景中，候选与父模型的完成率差。结合样本数、置信区间和退步情况阅读；40% → 50% 是提升 10 个百分点。
模型耗时与整局耗时请求等待、调用数、物理和渲染分别计时。分层一步可能有多个请求，单次 API 延迟不能代表整局效率。
候选概率当前输入与候选下的选择分布，不是任务成功概率。改动提示、候选或动作模式后不宜直接比较。

一项结果应能追溯到哪些证据

先找运行 ID 与整局 ID。 再核对模型／场景哈希、执行配置、成功协议、请求、动作结果与终止原因。训练还需数据清单、父模型、训练参数和独立评测记录。

阅读顺序：一个决策 → 一局任务 → 一轮训练。 先解释选择、执行和后果，再把曲线对应到数据与模型版本。

一次动作：从状态到可验证的物理结果

  1. 采样与投影

    读取当前状态或相机。真值直接投影，RGB-D 先检测，图像模式发送像素；审计数据与模型输入分开。

  2. 组织候选与历史

    按协议组织候选 ID、说明和近期结果。是否预先过滤或预演，取决于动作模式。

  3. 请求模型

    发送状态、指令与候选，记录顺序、回答和耗时。只有支持图像的路径才发送图片。

  4. 校验与选取

    验证 ID 与概率。RSI 评测通常取最大值，探索可采样；保留原始概率和调整后的分布。

  5. 预演与执行

    转换为 TCP 与夹爪命令，检查边界、IK 和接触，再执行。选中不等于执行。

  6. 反馈与收尾

    记录新的位姿、夹持、释放和终止原因，继续决策或结束整局。训练资格在整局结束后判断。

先定位失败发生在哪一层。 非法回答、执行拒绝、感知失效、碰撞和预算耗尽各有原因，不能只看最终“失败”标签。

三种动作模式，三种不同的决策分工

预设技能：模型选择动作意图，程序提供几何路径

模型选操作，程序给路径。 候选包括接近、抓取、抬升、搬运、释放等技能，带目标位置、夹爪命令和时长。几何路径与成功规则由代码定义。

展开：两条技能路径的差异

模型测试通常先选阶段，再选动作，可使用候选预演信息；RSI 根据当前阶段组织技能菜单。比较完成率时需同时核对阶段约束和候选构造。

src/embodied_jev/planning.pysrc/embodied_jev/runtime.pysrc/embodied_rsi/sim.pysrc/embodied_rsi/stage_prompts.py

逐步 XYZ：模型选择移动轴、方向和尺度

21 个离散命令：18 个移动 + 张开、闭合、保持。 三轴正负方向各有 40、10、2 毫米三档。模型逐步对齐并纠错，候选不按预测进展排名。

展开：为什么候选数量会变化

越界命令不裁剪。模型测试可展示被拒候选；RSI 请求只包含允许执行的项，所以一次请求不一定有 21 项。

模型看见什么：观测、相机与审计边界

观测来源提供给决策的内容适用范围与限制
仿真真值直接读取环境中的位置、本体与接触信息，按协议投影为结构化输入。它是明确标记的特权观测。模型测试和自主训练均支持。开启相机预览不表示图像会进入模型请求。
RGB-D 检测对选中相机的颜色与深度图进行检测、标定反投影与坐标估计，再把结构化结果交给模型。两条链路均支持，至少需要一个视角；当前检测依赖已知颜色、尺寸与场景规则。
直接图像将相机 RGB 作为原生图像载荷送给支持视觉的模型；保留 TCP、本体与接触反馈，限制物体／目标真值坐标。当前模型测试的逐步 XYZ 与支持图像的 Chat／Claude 路径可用。本地 RSI 训练仅支持文本／结构化状态，直接图像禁用。

RGB-D 是已知场景中的几何检测。 它使用颜色、深度、标定和尺寸先验；短时遮挡可跟踪，必要目标持续不可见则报错，不回退到真值。

启用相机不等于把图像交给模型。 相机在决策／动作边界采样，实际发送内容取决于观测协议。中央三维视图用于调试，模型输入以捕获记录和请求为准。

展开：各协议的观测权限

RSI 与逐步 XYZ 使用状态投影；旧模型测试技能路径可包含当前成功状态、场景和预演信息。以实际请求为准，核对 state、criteria 与图像载荷。

审计真值与模型观测分开。 before／after 用于核验物理结果，observed_before／observed_after 记录观测。日志出现真值，不代表它进入了模型请求。

src/embodied_jev/perception.pysrc/embodied_jev/evidence.pysrc/embodied_jev/incremental.pysrc/embodied_rsi/configured_sim.py

模型适配、候选概率与人工介入

适配器把回答变成可校验的选择。 请求包含状态、指令与候选；返回值需校验 ID、字段和概率。更换提示、候选或接口格式，就可能改变实验条件。

决策来源如何解读返回值
规则基线使用代码规则给出动作，是检查环境与执行链路的参照。没有实际模型调用，也没有模型原生候选概率；教师产生的数据需要单独标记。
本地 RSI / 结构化 Jev可返回候选概率。RSI 按当前菜单校验分布再进行最大值选择或采样；远端 Jev 的选择与概率分别保留，选择不是最大值时可以报告差异，不能改写为一条不存在的原始回答。
Chat / Claude解析结构化选择或工具返回；没有原生候选概率时不构造一组虚假概率。模型文字中的自报置信度不等于决策分布。

候选概率是选择偏好，不是任务成功率。 高概率仍可能不可达或执行失败。界面解释来自公开回答与运行证据，不是模型未公开的内部思考。

人工介入只控制低概率暂停。 接口须提供相应候选概率；关闭开关不关闭执行检查。非法输出、感知失效和碰撞仍按各自规则处理。

src/embodied_jev/policies.pysrc/embodied_rsi/policies.pysrc/embodied_rsi/exploration.py

从 TCP 目标到关节运动，再到成功判定

TCP 是末端控制点，IK 把目标位置转成关节姿态。 控制器用平滑插值推进 MuJoCo。物理步长为 0.002 秒，即每模拟秒 500 步，不等于模型请求频率或墙钟速度。

展开：执行检查覆盖什么

检查数值、边界、IK 误差与指定接触。RSI 先克隆预演再执行，模型测试按配置检查。检查覆盖范围由代码定义，通过预演不构成真实硬件的完整安全证明。

判定层级需要哪些实际证据
动作执行控制命令通过当前检查并实际推进了环境。它只说明这一步发生了，不说明抓取有效或整局成功。
基础放置成功方块与目标支撑面接触，水平误差小于 25 毫米，速度低于 25 毫米／秒，夹爪张开并稳定至少 0.4 秒，TCP 撤离到至少 170 毫米高度。
严格抓取与搬运成功在基础放置条件之外，审计稳定双指夹持、至少 30 毫米抬升、保持夹持的搬运、目标附近合规释放，以及无掉落、无禁止接触。新 RSI 默认使用此类严格协议。

成绩必须连同协议比较。 旧 checkpoint 会恢复绑定的 episode_protocol；复现时核对成功条件、动作、观测与场景分布。

src/embodied_jev/physics.pysrc/embodied_rsi/grasp.pysrc/embodied_rsi/sim.pysrc/embodied_rsi/episode_protocol.py

决策记录怎样接入训练与部署

训练需要完整决策证据。 保留状态、候选、原始概率、探索策略、选择、执行与审计；分层模式分别保存子目标和各通道标签。

先达阈值，再筛选。 新增整局与成功局同时达标才触发；排除失败、重复、仅评测和来源不合规的数据，再审计动作。执行与成功协议随数据保存。

冻结编码塔，只训练 scorer。 每轮继承父权重、新建优化器；开发集选 checkpoint，独立配对评测决定是否发布。

发布前核验，下一局切换。 核对哈希、加载预热后原子更新注册表。采集模型、训练候选与发布模型可能不同，应分别查看。

09常见问题

为什么采集停止了，self-improve 仍在运行？

采集与训练是两个任务。 已启动的 self-improve 会继续；在下方报告查看阶段，必要时单独停止作业。

为什么 loss 下降却没有发布新模型？

loss 衡量拟合，独立评测决定发布。 检查提升、置信区间、任务覆盖和风险门槛。

如何确认当前运行的是哪个模型？

核对左侧模型、版本、checkpoint 与 SHA256，再对照本局日志。训练候选不会在局中替换当前模型。

为什么配置了 API，训练页仍要求本地模型？

远端 API 提供推理，不提供当前训练器可更新的参数。 自主训练适配本地文本／结构化 RSI；其他模型需另接训练接口。

uv、RSI 环境或模型资源找不到怎么办？

检查项目根目录、uv 的 PATH 和 bootstrap 结果，再核对 .venv-rsi/bin/python、checkpoint 路径与哈希。下载或加载失败以终端和过程日志为准。

页面空白、资源过期或端口被占用怎么办？

完成 npm ci 和 npm run build，再刷新 /simulation。端口占用时使用独立端口；刷新界面无需重启正在训练的后端。

为什么日志 JSON 或模型回复没有翻译？

界面翻译，原始证据保留。 模型 ID、用户输入、原始回复、JSON 和代码保持原样。默认英文，语言选择保存在浏览器。
